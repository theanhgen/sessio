sessio

Find and resume your past Claude Code sessions — the right one, in the right directory — without hunting through claude --resume.

Latin · sessiō — a sitting, a session. The root the English word grew from.

This is not a screenshot or a recreation — it is sessio itself, compiled to WebAssembly and drawing the same frame it draws in your terminal, against six fixture sessions.

What it does

Three things, in the order you need them.

1Find the session

Projects run down the left; the sessions in one are browser-style tabs across the top.

  • Type to filter — literal matches first, fuzzy as a fallback.
  • ^f full-text search — greps every transcript body on disk, via ripgrep.
  • ^a archive — hide what you are done with. A session you work in again un-hides itself.

2See where you left off

The preview answers the question you actually have: what was this, and what happened last?

  • Claude's recap — the goal / state / whose-move paragraph it writes when you leave.
  • First and last prompt, then the last reply as rendered markdown.
  • ⏸ open — the tab that surfaces unanswered prompts, open questions, and folders with uncommitted changes.

3Pick it back up

Resume properly, or answer without leaving the list at all.

  • ↵ resume — runs claude --resume in the original directory.
  • Never twice — a ◉ means a claude is attached right now; ↵ names its pid and tty instead of starting a second one.
  • ^r reply — send one turn to a session without opening it, and stay where you are.
  • ↵ resumes in this window. Under Ghostty, ^o opens the session in a new window and keeps sessio running as a launcher.

Rust, no runtime dependencies. A cold scan of 300 sessions takes about 40ms, so nothing is cached and nothing goes stale.

Keys

KeyAction
↑ ↓Switch project
← →Move between session tabs (→ reveals more)
typeFilter by name / project / first prompt
^w / ⌥⌫Delete the last word of the query
^u / ⌘⌫Clear the whole query
^fFull-text search the current query across all transcripts
^aArchive / unarchive the selected session locally
^rReply to the session without opening it — sends one turn and leaves you in the list
⇥ / ^eGive the reply the whole preview box
↵Resume — if it is already running, says where instead; a second ↵ opens it twice anyway
^oResume in this window, skipping the already-running guard — and the escape hatch under Ghostty
?Toggle the full keybinding help
escClear content search, then quit

Install

zsh
# install (adds the `sessions` command)
$ npm install -g sessio

# run it
$ sessions

# optional: full-text search needs ripgrep
$ brew install ripgrep   # or: apt install ripgrep

Requires Node.js ≥ 16 to install and Claude Code (the claude binary on your PATH). macOS and Linux.

From source: sessio is Rust, shipped as a native binary, with Node needed only to install it. Build it yourself if you prefer:
$ cargo install --git https://github.com/theanhgen/sessio
Note: sessio reads Claude Code's transcript files at ~/.claude/projects/**/*.jsonl. That format is undocumented and internal to Claude Code — it may change without notice. sessio parses defensively and degrades gracefully, but this project is not affiliated with or endorsed by Anthropic.
